# พื้นฐานคอมพิวเตอร์และทักษะดิจิทัล

## ส่วนที่ 1: พื้นฐานคอมพิวเตอร์และระบบข้อมูล
1. **ฮาร์ดแวร์คอมพิวเตอร์**
   - ส่วนประกอบหลัก (CPU, RAM, Storage, Motherboard)
   - หน้าที่และการทำงานประสานกันของฮาร์ดแวร์
2. **ซอฟต์แวร์คอมพิวเตอร์**
   - ระบบปฏิบัติการคอมพิวเตอร์ (OS เช่น Windows, macOS, Android, iOS)
   - ซอฟต์แวร์เฉพาะ (Application Software สำหรับงานพิมพ์, ตารางคำนวณ, ฯลฯ)
3. **การจัดการข้อมูล**
   - โครงสร้างโฟลเดอร์ (Folder Hierarchy)
   - หลักการตั้งชื่อไฟล์ (Naming Conventions)
4. **การสำรองข้อมูล**
   - ความสำคัญของการสำรองข้อมูล
   - หลักการสำรองข้อมูลแบบ 3-2-1
5. **ฐานข้อมูล**
   - โครงสร้างฐานข้อมูลเบื้องต้น (Table, Record, Field)
   - ฐานข้อมูลเชิงสัมพันธ์ (Relational Database) เบื้องต้น

## ส่วนที่ 2: การใช้งานอุปกรณ์และอินเทอร์เน็ต
6. **การใช้งานอุปกรณ์เคลื่อนที่**
   - ประเภทระบบปฏิบัติการ (iOS / Android)
   - การจัดการแอปพลิเคชันและการตั้งค่าพื้นฐาน
   - ความปลอดภัยบนอุปกรณ์เคลื่อนที่
7. **การใช้งาน Cloud Computing**
   - ซอฟต์แวร์ในฐานะบริการ (SaaS)
   - พื้นที่จัดเก็บข้อมูลบนคลาวด์ (Cloud Storage)
   - ประโยชน์และการทำงานร่วมกัน (Collaboration)
8. **การใช้งานเว็บเบราว์เซอร์**
   - องค์ประกอบเบื้องต้น (Address Bar, Tabs, Bookmarks)
   - ประวัติการเข้าชม (History) แคช (Cache) และคุกกี้ (Cookies)
   - โหมดไม่ระบุตัวตน (Incognito Mode)
9. **การสืบค้นข้อมูล**
   - การใช้คำค้นหา (Keywords) ที่มีประสิทธิภาพ
   - เทคนิคการค้นหาขั้นสูง (ใช้เครื่องหมาย "", -)
   - การประเมินความน่าเชื่อถือของแหล่งข้อมูล

## ส่วนที่ 3: ทักษะดิจิทัลและการสื่อสารออนไลน์
10. **การใช้ E-mail**
    - โครงสร้างอีเมล (To, CC, BCC, Subject, Attachment)
    - มารยาทในการส่งอีเมลที่เป็นทางการ
11. **การใช้งานปฏิทินออนไลน์**
    - การสร้างนัดหมายและการเชิญผู้เข้าร่วม
    - การตั้งระบบแจ้งเตือน (Reminders)
12. **การใช้งานสื่อสังคมออนไลน์**
    - รอยเท้าดิจิทัล (Digital Footprint)
    - การตั้งค่าความเป็นส่วนตัว (Privacy Settings)
    - การรับสื่ออย่างมีวิจารณญาณ (Fake News)
13. **การใช้งานโปรแกรมการสื่อสาร**
    - แอปพลิเคชันแชทและข้อควรระวัง
    - มารยาทในการประชุมออนไลน์ (Video Conference Etiquette)
14. **การใช้ธุรกรรมอิเล็กทรอนิกส์**
    - การใช้งาน Mobile Banking และ E-Wallet
    - ความปลอดภัยทางการเงิน (OTP, การหลีกเลี่ยง Wi-Fi สาธารณะ)
